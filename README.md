# Lunar-Client-Offline-Account
Lunar-Client-Offline-Account is an offline mod for the paid version of the Minecraft Lunar Client launcher.<br /> 
All features are available, except cosmetic ones.

## Installation

Download files from the release.

### Instructions
Disable the lunar client— it's running in the background. Make sure you've disabled it everywhere.
write:
```bash
cd the\path\to\the\script

then write
```bash
python offline_mode.py

Done, the game is ready to launch.

The release also contains an exe file, run it if you don't have Python installed.
